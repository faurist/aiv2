# Pista AI V2 – Tool ügynök

A V2 már nem csak chatbot: a modell eszközöket hívhat.

## Eszközök
- `web_search` – Tavily segítségével webes keresés
- `calculator` – biztonságos karakterkészletű alap számolás

## Telepítés
npm install
npm start

`.env`:
GEMINI_API_KEY=...
GROQ_API_KEY=...
TAVILY_API_KEY=...

Render:
Build: npm install
Start: npm start

A Tavily kulcs nélkül a web tool nem aktív.
